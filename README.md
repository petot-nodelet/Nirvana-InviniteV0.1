# NeoTemplate

Situs undangan digital statis yang dapat dideploy langsung ke Netlify.

## Deploy ke Netlify

1. Upload folder ini ke GitHub.
2. Buka Netlify dan pilih "Add new site" > "Import from Git".
3. Pilih repository yang berisi folder ini.
4. Set publish directory menjadi `.` atau biarkan default jika repo root adalah folder ini.
5. Klik Deploy site.

## Catatan

- File utama: `index.html`
- File template lain: `template1_classic_matcha.html`, `template2_modern_minimalist.html`
- Konfigurasi Netlify ada di `netlify.toml`
